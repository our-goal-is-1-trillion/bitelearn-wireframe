# [UT 계획서] Bitelearn 서비스 흐름 및 학습 완결성 검증 (Maze 비대면 테스트)

> **배경 및 목적**: 모더레이터 없이 다수의 유저를 대상으로 정량적 데이터를 수집하기 위해, **비대면 UT 툴인 Maze**를 활용한 테스트 기획안입니다. 사용자가 전체적인 학습 흐름(단어 → 서류 → 상황 기반 퀴즈)을 자연스럽게 이해하고, 중도 이탈 없이 학습 완료까지 도달하는지를 검증합니다.

---

## 1. 테스트 목적
사용자가 Bitelearn의 핵심 가치인 '실전 시뮬레이션 마이크로러닝' 흐름을 별도의 가이드 없이도 직관적으로 따라갈 수 있는지, 그리고 각 학습 단계 전환 시 포기(Give up)나 이탈 요소가 없는지 확인합니다.

---

## 2. 테스트 대상 화면 (User Flow 순서)
1. **홈 & 카테고리**: 학습 진입 및 탐색 (대시보드에서의 시작 씬)
2. **단어 학습**: 기초 용어 학습 및 인지 (스와이프/플립형 플래시카드)
3. **서류 판독 퀴즈**: 실제 등기부등본 데이터를 직접 확인하고 조작하는 실전 훈련
4. **상황 기반 퀴즈**: 카톡 대화형, OX 등 실무 시나리오 적용 문제 풀이
5. **나의 학습 노트**: 학습 결과(바이트 등락) 확인 및 오답 복습 유도

---

## 3. 검증 가설 (Hypothesis)
- **H1. [학습 완결성]**: 사용자는 마이크로러닝 흐름을 직관적으로 이해하며, **5~7분 내에 전체 학습 과정을 끝까지 완료(Task Completion)**할 수 있을 것이다.
- **H2. [서류 UI 직관성]**: 텍스트 필드를 직접 터치해야 하는 퀴즈 방식을 큰 혼란(Misclick) 없이 수행해 낼 것이다.
- **H3. [정보 구조 인지]**: 오답 노트(나의 학습 노트)와 보상(뱃지 모달) 확인 메뉴 진입이 유저의 멘탈 모델과 일치하여, 예상치 못한 곳으로 이탈하지 않을 것이다.

---

## 4. Maze Block 구성 및 미션(Mission) 시나리오

비대면 테스트이므로 테스터가 상황에 몰입할 수 있는 명확한 **맥락(Context)**과 **지시(Mission)**를 제공합니다.

### 📋 Block 1: 웰컴 스크린 & 사전 설문 (Multiple Choice)
- **메시지**: "안녕하세요! 부동산/경제 용어를 실전처럼 훈련하는 'Bitelearn'의 사용성 테스트입니다."
- **Q1**: 평소 모르는 부동산/계약 용어가 나오면 주로 어떻게 하시나요? (검색 / 무시 / 질문 / 유튜브 시청 등)
- **Q2**: 평소 듀오링고 같은 퀴즈/학습용 앱을 사용해 보신 적이 있나요? (예 / 아니오)

### 🎯 Block 2: 미션 1 - 핵심 학습 플로우 완수 (Mission & Heatmap)
- **Context**: "당신은 곧 방을 구해야 해서, 전세계약 관련 지식을 학습해 보려고 합니다."
- **Mission**: 홈 화면의 '학습 시작하기'를 눌러, **단어장부터 시작해 준비된 퀴즈를 모두 풀고 최종 결과 화면까지** 도달해 보세요.
- **관찰 지표 (Maze 자동 수집)**: 
  - 미션 통과율 및 도중 포기(Give up) 비율
  - 단어장 화면에서의 스와이프/플립 클릭 히트맵 패턴

### 🎯 Block 3: 미션 2 - 서류 퀴즈 UI 직관성 테스트 (Click Test)
- **Context**: "퀴즈 도중, 등기부등본 이미지를 보고 위험 요소를 찾아야 하는 상황입니다."
- **Mission**: 문제의 지시를 읽고, **등기부등본 서류 이미지 영역 중에서 '정답이라고 생각하는 부분' 자체를 직접 터치**하세요.
- **관찰 지표**: First Click 영역 분석 (하단 UI가 아닌 서류 이미지를 눌렀는지), 미클릭률(Misclick Rate)

### 🎯 Block 4: 미션 3 - 정보 구조 파악 (Mission)
- **Context**: "학습을 마치고 바이트(재화) 현황을 확인했습니다."
- **Mission 4-A (복습)**: 내가 틀린 문제들을 모아볼 수 있는 곳을 찾아보세요. (의도된 경로: 하단 GNB '노트' 탭)
- **Mission 4-B (보상)**: 내가 모은 '뱃지'를 확인할 수 있는 곳을 찾아 열어보세요. (의도된 경로: 홈 상단 뱃지 아이콘)

## 5. 측정 지표 및 데이터 분석 (KPI & Metrics)
Maze 결과 리포트를 분석하여 기능 고도화 방향(Action Item)을 결정합니다.

| 지표명 (Metric) | 측정 내용 (Maze 데이터 기준) | 해석 가이드 |
| :--- | :--- | :--- |
| **Task Completion Rate** | 부여된 학습 태스크를 끝까지 완료한 사용자의 비율 | **Direct Success(주경로 성공)**가 80% 이상인지 확인. **Indirect Success(우회 성공)** 비중이 높다면 도중 헤맸다는 의미. |
| **Time on Task** | 각 단계별 체류 시간 및 전체 학습 완료까지 소요된 총 시간 | 5~7분 목표. 특정 화면 체류 시간이 유독 길다면 난이도 조절 필요 |
| **Drop-off Point** | 특정 미션에서 진행을 못하고 이탈(Give up)한 비율과 지점 파악 | সবচেয়ে 시급히 개선해야 할 심각한 사용성 문제 구간 (예: 브리핑 대기 화면) |
| **Confusion Point (Misclick Rate)** | 화면 내에서 클릭 실수가 잦거나(Misclick) 엉뚱한 버튼 영역을 누른 비율 | 히트맵(Heatmap) 분석을 통해 혼동을 일으키는 UI 요소를 제거하거나 '힌트 펄스' 등 어포던스를 강화해야 함 |
| **Navigation Path** | 목표 메뉴를 찾기 위한 첫 클릭(First Click) 성공 비율 | 마이페이지 등 엉뚱한 곳을 먼저 클릭(비율 높음)한다면 유저의 예상 경로(멘탈 모델)와 앱 구조가 불일치함 |

---

## 6. 사후 요약 설문 (User Feedback - Opinion Scale & Open Question)

모더레이터가 없으므로 텍스트 작성을 최소화하고, 선택형 척도(Opinion Scale)를 적극 활용합니다.

1. **[목적 인지도 조절 - 1~5점 척도]** "오늘 방금 겪으신 이 앱이 부동산 계약 리스크를 대비하는 데 실질적인 도움을 줄 수 있다고 느끼셨나요?" (1점: 전혀 아님 ~ 5점: 매우 그렇다)
2. **[서류 UI 만족도 - 1~5점 척도]** "단순히 글을 읽는 게 아니라, 실제 서류(등기부등본 등)를 직접 터치하며 문제를 푸는 방식의 난이도는 어떠셨나요?" (1점: 너무 어렵고 불친절함 ~ 5점: 직관적이고 몰입됨)
3. **[주관식 문항]** "전체 진행 과정에서 내 의도대로 안 눌리거나 흐름이 끊겨서 짜증 났던 지점이 있다면 한 가지라도 자유롭게 적어주세요."
