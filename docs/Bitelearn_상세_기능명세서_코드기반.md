# Bitelearn 기능 명세서 (코드 기반 정밀 분석본)

> **작성 기준**: 프로젝트 내 모든 페이지, 컴포넌트, 라우팅 로직, 목업 데이터를 직접 분석하여 실제 구현된 기능만 기재.
> **우선순위 기준**: P0 = 서비스 작동에 필수 · P1 = 서비스 가치에 핵심 · P2 = 부가/폴리시 기능

## 3. 학습 (Tab 2: 학습)

### 3-1. 학습 홈 & 챕터 탐색

| 우선순위 | 기능 ID | 기능명                         | 상세 설명                                                                                                                                                                                                                   |
| :------: | :------ | :----------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  **P1**  | LRN_01  | 자산 현황 히어로 (통장 뱃지)   | 유저 누적 EXP에 따라 뱃지를 3단계(🤎낡은 저금통 → 💳든든한 통장 → 💎프리미엄 금고)로 분기 표시. 총 보유 바이트(B) 수치와 다음 뱃지까지의 프로그레스바 포함. 뱃지 아이콘 탭 시 뱃지 컬렉션 모달이 열림.                      |
|  **P1**  | LRN_02  | 뱃지 컬렉션 모달               | **학습 탭에서 모달(Dialog)로 열림** (마이페이지 아님). 자산·도메인 마스터·업적 3개 그룹으로 배지 나열. 해제=검정 배경+체크 / 잠금=점선+자물쇠+반투명 시각 구분.                                                             |
|  **P0**  | LRN_03  | 지금 당장 이어하기 CTA         | 현재 진행 중 또는 다음 가용 챕터를 자동 탐색해 카테고리+제목을 CTA 카드로 표시. 탭 시 해당 챕터 목록으로 이동.                                                                                                              |
|  **P0**  | LRN_04  | 지식 금고 현황 (카테고리 카드) | 4개 카테고리별 이모지·이름·태그라인·진행률 프로그레스바. 완료 카테고리는 "⭐완료" 배지, 미완료는 그레이스케일 적용. 탭 시 챕터 로드맵으로 이동.                                                                             |
|  **P0**  | LRN_05  | 챕터 로드맵 (지그재그 노드)    | SVG 곡선 배경 위에 노드를 좌우 지그재그로 배치한 로드맵. 노드 상태 4종: ✅완료(검정+체크) / 🔵진행중(파란 테두리+펄스 애니메이션) / ⬜대기("다음 챕터") / 🔒잠금(회색+자물쇠, 클릭 불가). 상단에 카테고리 전체 진행률 카드. |
