# [UT 계획서] BiteLearn 서비스 흐름 및 학습 완결성 검증

> **배경 및 목적**: 사용자가 서비스의 전체적인 학습 흐름(단어 → 서류 → 상황 기반 퀴즈)을 직관적으로 이해하고, 중도 이탈 없이 자연스럽게 학습 완료 및 복습 단계까지 도달하는지를 검증하기 위한 사용성 테스트(UT) 계획서입니다.

---

## 1. 테스트 목적
사용자가 BiteLearn의 핵심 가치인 '실전 시뮬레이션 마이크로러닝' 흐름을 별도의 가이드 없이도 자연스럽게 따라갈 수 있는지, 그리고 각 학습 단계 전환 시 마찰(Friction)이나 이탈 요소가 없는지 확인합니다.

---

## 2. 테스트 대상 화면 (User Flow 순서)
1. **홈 & 카테고리**: 학습 진입 및 탐색 (대시보드에서의 시작 씬)
2. **단어 학습**: 기초 용어 학습 및 인지 (스와이프/플립형 플래시카드)
3. **서류 판독 퀴즈**: 실제 등기부등본 데이터를 직접 확인하고 터치하는 실전 훈련
4. **상황 기반 퀴즈**: 카톡 대화형, OX 등 실무 시나리오 적용 문제 풀이
5. **나의 학습 노트**: 학습 결과 확인 및 오답 복습 유도 (리텐션 루프)

---

## 3. 검증 가설 (Hypothesis)
- **H1. [완결성]** 사용자는 BiteLearn이 제공하는 마이크로러닝 흐름을 별도 가이드 없이 직관적으로 이해하며, **5~7분 내에 전체 학습 과정을 끝까지 완료**할 수 있을 것이다.
- **H2. [학습 효과성]** 문제 유형의 다변화(단어 → 서류 → 상황) 구성이 지루함을 없애고, 실제 실무 맥락을 이해하는 데 도움을 줄 것이다.
- **H3. [행동 유도]** 문제 풀이 완료 및 결과 화면(바이트 획득/손실 피드백) 이후, 사용자는 헤매지 않고 자연스럽게 다음 행동(오답 노트 이동 또는 다음 챕터 학습)을 선택할 수 있을 것이다.

---

## 4. 측정 지표 (KPI)
성공적인 UX 설계를 검증하기 위해 다음의 정량 및 정성 지표를 측정합니다.

| 지표명 (Metric) | 측정 내용 |
| :--- | :--- |
| **Task Completion Rate** | 부여된 학습 태스크(단어~결과 확인)를 이탈 없이 끝까지 완료한 사용자의 비율 |
| **Time on Task** | 각 단계별(단어/서류/상황) 체류 시간 및 전체 학습 완료까지 소요된 총 시간 |
| **Drop-off Point** | 학습 과정 중 어느 화면에서 가장 많이 학습을 포기하거나 이탈하는지 확인 (이탈 지점) |
| **Confusion Point** | 화면 내에서 클릭 실수가 잦거나(Misclick) 오랜 시간 머뭇거리는 지점 (혼란 지점, 예: 서류 퀴즈 터치 영역) |
| **Navigation Path** | 사용자가 기획된 의도 순서대로 화면을 이동하는지, 혹은 다른 탭(마이페이지 등)으로 잘못 이탈하는지 분석 |
| **User Feedback** | 학습 난이도, 분량의 적절성 및 UI 직관성에 대한 사용자의 주관적인 평가 (인터뷰/설문) |

---

## 5. 핵심 질문 (User Interview & Survey)
테스트 완료 후(또는 Maze의 경우 사후 설문 블록) 테스터에게 던질 핵심 질문 리스트입니다.

1. **서비스 인지**: "오늘 경험하신 서비스가 주로 어떤 목적으로 만들어진 서비스라고 생각하시나요?"
2. **인터랙션 평가**: "단순히 글을 읽는 게 아니라, 실제 서류(등기부등본 등)를 부분적으로 직접 터치하며 문제를 푸는 과정은 어떠셨나요?"
3. **페인포인트 탐색**: "전체 진행 과정에서 가장 망설여졌거나 조작의 흐름이 끊겼다고 느낀 지점은 어디인가요?"
