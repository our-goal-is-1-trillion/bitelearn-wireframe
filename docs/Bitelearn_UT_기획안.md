# 바이트런(Bitelearn) 비대면 사용성 테스트(UT) 기획안 (Maze 활용)

> **배경 및 목적**: 모더레이터(진행자) 없이 다수의 유저를 대상으로 정량적 데이터를 수집하기 위해, **비대면 UT 툴인 Maze**를 활용한 테스트 기획안입니다. 사용자의 실제 클릭 히트맵(Heatmap), 미션 성공률(Direct/Indirect Success), 오클릭률(Misclick Rate) 등의 지표를 통해 현재 UI/UX의 병목을 진단합니다.

---

## 1. 테스트 플랫폼 및 환경 설정

*   **테스트 툴**: Maze (maze.co)
*   **테스트 대상물**: Figma 프로토타입 연결 (또는 실제 앱 URL 연동)
*   **타겟 테스터**: 2030 사회초년생, 자취생 (금융/부동산 지식이 부족한 타겟)
*   **모집 인원**: 최소 30명 ~ 50명 (정량적 통계 유의성 확보 목적)
*   **예상 소요 시간**: 유저당 5~10분 내외 (Unmoderated, 자유 시간 접속)

## 2. 테스트 핵심 목표 및 검증 지표 (KPI)

| 테스트 영역 | 검증 가설 / 유저 상황 | Maze 주요 측정 지표 (Metrics) |
| :--- | :--- | :--- |
| **A. 온보딩 & 첫인상** | 4단계 온보딩이 서비스의 가치를 직관적으로 전달하는가? | • 첫 화면 이탈률 (Bounce Rate)<br>• 온보딩 완료까지 걸리는 시간 |
| **B. 핵심 학습 흐름<br>(단어장 → 퀴즈)** | 플래시카드(스와이프/플립) 학습 후 퀴즈로 이어지는 긴 플로우를 유저가 포기하지 않고 완료하는가? | • 미션 성공률 (완료화면 도달 비율)<br>• 퀴즈 진입 대기화면에서의 이탈(Give up) 비율 |
| **C. 인터랙티브 서류 퀴즈** | 텍스트 필드를 직접 터치해야 하는 퀴즈 방식을 첫 시도에 바로 깨닫는가? | • 최초 탭(First Click) 영역 분석<br>• 미클릭률(Misclick Rate) 및 히트맵 분포 |
| **D. 정보 구조 (IA) 인지** | 오답 노트와 보상(뱃지) 확인 메뉴가 유저의 멘탈 모델(Mental Model)과 일치하는가? | • 목표 메뉴를 찾기 위한 첫 클릭(First Click) 성공 비율<br>• 예상 경로 외의 화면(예: 마이페이지)으로 진입하는 간접 성공/실패 비율 |

## 3. Maze Block 구성 및 미션(Mission) 시나리오

비대면 테스트이므로 지시문(지문)은 명확하고 단순해야 하며, 테스터에게 충분한 맥락(Context)을 부여해야 합니다.

### 📋 Block 1: 웰컴 스크린 & 사전 설문 (Multiple Choice)
- **메시지**: "안녕하세요! 어려운 어른 용어를 퀴즈로 알려주는 '바이트런' 앱의 사용성 테스트입니다."
- **Q1**: 평소 모르는 경제/부동산 용어가 나오면 주로 어떻게 하시나요? (검색 / 무시 / 질문 / 유튜브 시청 등)
- **Q2**: 듀오링고 같은 교육용 게임 앱을 1달 이상 써본 적이 있나요? (예 / 아니오)

### 🎯 Block 2: 미션 1 - 온보딩 및 첫 진입 (Opinion Scale)
- **Context**: "당신은 방금 앱을 처음 설치했습니다. 앱이 어떤 서비스를 제공하는지 화면을 넘겨보며 확인해 주세요."
- **Mission**: 온보딩 4단계를 확인하고 홈 화면(대시보드)으로 넘어가세요.
- **예상 정답 경로**: 온보딩 '다음' 버튼 3회 클릭 👉 '시작하기' 👉 홈 화면 로드
- **Post-Mission Question (1-5점 척도)**: "방금 본 화면들만으로 이 앱이 당신에게 어떤 도움을 줄 수 있는지 명확히 이해하셨나요?"

### 🎯 Block 3: 미션 2 - 핵심 학습 플로우 완수 (Mission & Heatmap)
- **Context**: "당신은 현재 전세계약에 관심이 생겼습니다. 부동산 관련 지식을 학습해 보려고 합니다."
- **Mission**: 홈 화면의 '오늘의 추천 학습(또는 부동산 카테고리)'을 눌러, **단어장부터 시작해 퀴즈를 모두 풀고 결과 화면까지 끝까지 진행**해 보세요.
- **관찰 지표 (Maze 자동 수집)**: 
  - 미션 도중 포기(Give up) 비율 및 화면별 체류 시간
  - 단어장(스와이프/뒤집기) 화면에서 제스처를 위한 클릭 히트맵 패턴

### 🎯 Block 4: 미션 3 - 퀴즈 툴 사용성 (Click Test)
- **Context**: "등기부등본 읽는 법을 퀴즈로 풀고 있습니다."
- **Mission**: 문제 지시를 읽고, **등기부등본 서류 이미지 영역 중에서 정답이라고 생각하는 부분**을 직접 터치하세요.
- **관찰 지표 (Maze 자동 수집)**: 
  - First Click 영역 분석 (서류 안을 눌렀는지, 하단/기타 UI를 눌렀는지)
  - Misclick Rate (잘못된 영역을 탭한 비율이 높다면 UI 어포던스 부족)

### 🎯 Block 5: 미션 4 - 게임화 및 정보 구조 파악 (Mission)
- **Context**: "학습을 마쳤습니다. 퀴즈에서 오답이 있어 바이트(B)를 잃었다고 합니다."
- **Mission 4-A (오답 복습)**: 오늘 내가 틀린 문제들을 어디서 모아볼 수 있는지 찾아보세요.
  - *예상 정답 경로*: 하단 GNB '노트' 탭 클릭
- **Mission 4-B (보상 확인)**: 지금까지 내가 모은 '뱃지'들을 확인할 수 있는 메뉴를 찾아보세요.
  - *예상 정답 경로*: 2번째 탭 '학습' 홈의 상단 👉 뱃지(저금통) 아이콘 클릭
- **관찰 지표**: First click이 다른 곳(마이페이지 탭 등)으로 향하는지 비율 측정 (유저의 직관과 실제 앱 구조의 일치 여부 평가)

### 📋 Block 6: 사후 요약 설문 (Open Question & Opinion Scale)
- **Q1**: 앱을 사용해 보시면서 제일 재미있었거나 인상 깊었던 점은 무엇인가요? (주관식)
- **Q2**: 진행하시면서 직관적이 않거나 조작하기 헷갈렸던 부분이 있다면 적어주세요. (주관식)
- **Q3 (NPS)**: "이 앱을 경제/독립 지식이 부족한 주변 사회초년생 친구에게 추천할 의향이 얼마나 있으신가요?" (0~10점 척도)

## 4. 데이터 분석 방법 및 액션 플랜 도출 (Post-UT)

테스트 종료 후 Maze의 결과 리포트를 분석하여 기능 고도화 방향(Action Item)을 결정합니다.

### 📊 주요 리포트 지표 해석
*   **Direct Success (직접 성공률)**: 예상 경로대로 헤매지 않고 한 번에 성공한 유저 비율. (높을수록 UI가 직관적임을 입증)
*   **Indirect Success (간접 성공률)**: 헤매거나 다른 경로를 거쳐 결국 미션을 완수한 유저 비율. (이 비율이 높으면 해당 기능으로 통하는 주경로 UI의 개선 여지 있음)
*   **Give up / Bounce (포기 및 이탈률)**: 특정 미션 파일에서 진행을 못하고 이탈한 비율. (가장 시급히 개선해야 할 심각한 사용성 문제 구간)
*   **Misclick Rate (오클릭률)**: 정답 경로와 상관없는 빈 공간이나 엉뚱한 버튼, 이미지 영역을 누른 비율. 히트맵 트래킹을 통해 혼동을 일으키는 UI 요소를 제거하거나 힌트를 추가해야 함.

### 💡 예상되는 개선 액션 포인트 예시
1. **서류 퀴즈 미클릭률이 30% 이상일 경우**:
   - 진입 시 최초 1회, 탭 가능한 필드 영역에 '펄스(Pulse)' 애니메이션 보조 도구나 힌트 손가락 아이콘(`Pointer`)을 추가하여 어포던스 부여.
2. **뱃지 확인 미션에서 마이페이지(5번째 탭) First Click 비율이 높을 경우**:
   - 학습 탭 홈 상단에만 있던 뱃지 진입을 **마이페이지에도 메뉴로 추가 배치**하여 유저의 예상 경로(Mental Model)와 일치시킴.
3. **핵심 학습 플로우에서 브리핑(대기) 화면 이탈률이 20% 이상일 경우**:
   - 단어 학습과 퀴즈 사이의 연결 호흡이 길어 피로함을 느끼는 것이므로, 단어 카드 개수를 줄이거나 브리핑 화면의 텍스트를 대폭 덜어내어 빠른 전환 유도 (Bite-sized 원칙 강화).
