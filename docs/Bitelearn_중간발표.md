# Bitelearn 서비스 중간 발표

## 01. 프로젝트 개요 및 배경
- **프로젝트명**: Bitelearn
- **서비스 소개**: 5분, 부동산 계약 리스크를 풀이로 학습하는 마이크로러닝 서비스
- **팀명**: 우리 목표는 1조
- **팀원 구성**:
  - **PM**: 이성민, 장세혁, 한보름
  - **PD**: 은석기, 박시원
  - **FE**: 최아로인
  - **BE**: 백유정

**배경 및 목적**
- **서비스 정의**: 사회초년생이 부동산 계약 시 겪는 리스크를 짧고 반복적인 문제 풀이로 학습하는 서비스
- **핵심 문제**: 고관여 계약 상황에서 판단 기준 부재로 인한 의사결정에 어려움을 겪음
- **현재 목표**: 부동산 계약 학습 MVP의 핵심 범위 정의 및 구현 현황 공유
- **왜 지금 이 문제인가**: 전세사기 피해는 20~30대 청년층 비중이 높고, 사회초년생에게 실제 손실 위험이 큰 영역

---

## 02. 사용자 리서치 및 시장 분석
**페르소나: 김병수 (29세, 중소기업 2년차)**
- **문제점**: 단편적인 지식은 있으나 실제 리스크 판단 기준 부족
- **막연한 공포**: 무엇을 확인해야 하는지 모름
- **단편 지식**: 확정일자만 받으면 안전하다는 오해
- **즉시 적용 욕구**: 실전형 단기 학습 선호

**설문 결과 (n=28)**
- **78.6%**: 계약 내용을 충분히 이해하지 못해 곤란을 겪은 경험
- **96.4%**: 관련 교육 필요
- **96.4%**: 서비스 이용 의향 있음
- **89.3%**: 사례 중심 설명이 가장 도움 된다고 응답

---

## 03. 경쟁 서비스 분석 및 차별화
**기존 서비스 분석의 한계**
- **거래/기능 중심**: 단순 송금 및 대출 정보, 계약 과정 가이드 부재
- **흥미/설명 중심**: 일방향적 정보 전달, 내 상황 적용 어려움
- **정확한 정보제공 중심**: 방대한 텍스트 위주, 실시간 질의 불가
> **한계**: 기존 서비스는 정보 전달에는 강점이 있지만, 사용자가 실제 계약 상황에서 판단하는 경험까지는 충분히 제공하지 못함

**Bitelearn (Our Solution)**
- 실전 문해력 학습 중심
- 5분 마이크로러닝
- 문제풀이 기반 판단 훈련

---

## 04. 서비스 전략 및 MVP 설계 (가설 검증 및 방향 수정)
**초기 방향 vs 현재 방향**
- **초기 방향**: 금융 생활 계약 전반 (노무·세금·부동산 등 일상생활의 다양한 계약 분야를 포괄적으로 다루는 서비스)
- **현재 방향 (MVP)**: **부동산 계약 집중**

**방향 조정의 핵심 이유**
- **타겟 적합성**: 전세사기 피해자 중 청년층 비중이 가장 높음
- **문제 심각성**: 실제 금전적 손실 규모가 크고 회복이 어려움
- **검증 효율성**: 명확한 페인포인트로 MVP 검증에 적합

---

## 05. MVP 핵심 기능 및 학습 구조
**왜 문제 풀이인가? (WHY?)**
- 지식 이해와 실제 판단 사이의 격차 해소
- 사용자가 수동적으로 정보를 읽는 것이 아니라, 직접 판단하고 결정하는 능동적 학습 경험 설계

**핵심 기능**
- **단어 기반**: 어려운 부동산 용어를 퀴즈로 쉽게 이해
- **서류 기반**: 등기부등본 등 실제 서류의 핵심 리스크 판독 훈련
- **상황 기반**: 계약 현장 시뮬레이션으로 대처 능력 배양

**Core User Flow**
`대시보드 (학습현황)` → `주주제선택 (카테고리)` → `문제 풀이 (판단 훈련)` → `해설 확인 (즉시 피드백)` → `오답 노트 (학습현황)`

---

## 06. 목표 지표 및 성공 기대효과 (KPI)
**정성 목표**
- **지속 가능한 지식 습득**: 5분 부담 없는 마이크로러닝으로 사회 초년생의 꾸준한 부동산 학습 루틴 형성
- **리스크 예방 역량 강화**: 등기부등본 및 특약사항의 위험 요소를 스스로 발견하고 대처하는 실질적 능력 배양
- **실제 계약 상황에서의 판단 자신감 확보**: 다양한 시뮬레이션 경험을 통해 막연한 불안감을 해소하고 주체적인 계약 진행 가능

**정량 목표**
- **60%**: 학습 활성 유저
- **75%**: Day 3 Retention
- **85%**: 단일 학습 주제 완료율

---

## 07. 직군별 개발 진행 현황 및 피드백 반영
- **PM (프로덕트 매니지먼트)**
  - PRD 작성 및 문서 상세화
  - 학습 구조 명확화: 단어형·서류형·상황형 3가지 문제 유형 설계
  - 학습 시나리오 고도화
- **FE (프론트엔드)**
  - 앱 레이아웃 및 화면 간 라우팅 구조 구성 완료
  - lo-fi 와이어프레임 기반 전체 화면 UI 구현 완료
  - 기능 구현 중심으로 개발 진행 예정
- **PD (프로덕트 디자이너)**
  - 유저 플로우·IA 및 Lo-fi 와이어프레임 설계
  - MVP 범위 확장(전세사기 사회초년생 금융지식) 및 BM 설계
  - Hi-fi 디자인 제작 → 프로토타입 UT → 디자인 QA 진행
- **BE (백엔드)**
  - ERD, API 명세서 완료, 회원가입/로그인 로직 완료
  - PD/FE 목업 구조에 맞는 Response 설계 및 로그인 인증 방식 개선
  - 우선순위에 맞는 기능 개발

---

## 08. 프로토타입 데모
**데모 포인트 (Core User Flow: 대시보드 → 주제선택 → 문제 풀이 → 피드백)**
1. **짧은 문제 풀이 (Micro-Learning)**: 8분 내외의 짧은 호흡으로 구성된 퀴즈를 통해 지루함 없이 핵심 개념을 빠르게 습득합니다.
2. **실전 판단 (Judgment)**: 실제 계약서와 등기부등본 이미지를 보고 위험 요소를 직접 찾아내는 실전형 훈련을 제공합니다.
3. **해설 학습 (Feedback)**: 정답/오답에 대한 즉각적인 상세 해설을 통해 단순히 답을 맞추는 것을 넘어 원리를 이해합니다.
> **Bitelearn은 사용자가 실제 계약 상황을 기반으로 문제를 풀면서 리스크 판단 기준을 학습하는 서비스입니다.**

**향후 계획**
- **Must-Have**: 부동산 계약 3종(월세·전세·매매) 학습 경로 구체화
- **Next Step**:
  - 문제 풀이 핵심 플로우 완성
  - 해설 및 오답 노트 기능 연결

  - 타 카테고리(노무, 세금 등) 확장 검토

**마무리**
