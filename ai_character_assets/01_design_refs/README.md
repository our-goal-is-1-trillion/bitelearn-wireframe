# 01 Design References (캐릭터 디자인 참고)

이 폴더에는 캐릭터의 디자인을 구체화하기 위한 이미지 레퍼런스를 보관합니다.
(예: 특정 의상 디자인, 독특한 헤어스타일, 액세서리 디테일, 신발, 체형 특징 등)

- **AI 활용 목적**: 캐릭터의 외형 특징을 정확히 묘사하고 일관성 있게 생성하기 위한 이미지 레퍼런스로 사용합니다.
- **권장 사항**: 파일명에 어떤 부분을 참고해야 하는지 명시해 두면 좋습니다. (예: `reference_hair_style.png`, `reference_jacket.jpg`)
