# 🎯 학습 도메인 3D 아이콘 프롬프트 가이드라인

## 1. 핵심 디자인 원칙 (UI 아이콘 최적화)
- **Scalability (축소성 고려)**: 홈 대시보드 및 학습 화면의 작은 영역에 배치되므로, 얇은 선이나 복잡한 디테일을 배제하고 **단순하고 볼드한(Bold) 형태론**을 취해야 합니다.
- **Single Object Focus (단일 오브젝트 집중)**: 아이콘으로서 기능할 수 있도록 여러 요소가 섞이지 않은 **거대한 단일 핵심 메타포**에 집중합니다.
- **Consistent Style (기존 3D 펠트 아트와의 조화)**: 기존 캐릭터(멍멍이 등) 및 시나리오와 유사한 **Premium 3D Felt Art (무광 펠트)** 질감으로 따뜻하고 친근한 느낌을 줍니다.
- **Vibrant & Clear Colors (명확한 색상 대비)**: 작을 때도 알아볼 수 있도록 도메인별 고유의 명확한 테마 컬러를 사용합니다.
- **Strict Background (백색 배경 고정)**: 모든 이미지 배경은 앱 내 투명화/조화를 위해 **#FAFAFA (Off-white)** 단색 펠트로 고정합니다. (스튜디오 조명)
- **No Text (글자 금지)**: 아이콘 내부에는 글자, 기호를 넣지 않고 형상만으로 표현합니다.

## 2. 도메인별 메타포 제안 및 가이드

| 도메인 | 핵심 메타포 제안 | 주요 색상(포인트) | 상태/피드백 표현 요건 |
| :--- | :--- | :--- | :--- |
| **부동산/주거** | 둥글고 단순한 지붕을 가진 모던한 프미리엄 3D 집 모형 또는 열쇠 | 파스텔 오렌지 & 따뜻한 브라운 | 디테일을 최소화한 큰 덩어리감 |
| **생활금융/고용** | 두툼하고 귀여운 가죽 지갑, 또는 둥근 동전 더미 | 머스타드 옐로우 & 소프트 그린 | 돈의 복잡한 무늬 배제 |
| **커리어/세무** | 계단식으로 우상향하는 3D 블록 차트, 또는 거대한 스탬프(도장) | 네이비 블루 & 연한 스카이블루 | 꺾은선보다는 두꺼운 블록(막대) 권장 |
| **자산운용/투자** | 황금빛 둥근 돼지저금통, 또는 비옥한 흙 위에 돋아난 식물 | 골드 & 비비드 그린 | 반짝이는 금속 대신 펠트의 부드러움 강조 |

## 3. 프롬프트 템플릿 예시
> 도메인 아이콘 생성 시 다음 템플릿을 엄격하게 유지하여 일관성을 확보합니다.

`A highly simplified, bold premium 3D felt art icon of a [핵심 메타포: e.g., rounded modern house]. The object is very simple and large, designed to be clearly visible when scaled down as a UI icon. It features [주요 색상] soft felt texture. NO intricate details, NO text, NO characters. Plain Solid #fafafa off-white felt background. Professional studio lighting with soft shadows, minimalist app icon style.`

## 4. 리뷰 및 개선 방향
- 생성 후 모바일에 들어갈 수 있는 사이즈(예: 48x48px ~ 64x64px)로 시야를 좁혀보았을 때 형태 식별이 가능한가 확인.
- 기존 캐릭터/오브젝트 자산들과 질감 톤 앤 매너가 맞는가 확인.
