# 03 Style References (캐릭터 화풍 참고)

이 폴더에는 캐릭터를 그릴 때 사용할 구체적인 아트워크 스타일이나 화풍의 레퍼런스를 보관합니다.
(예: 굵은 펜선과 팝아트 느낌, 수채화풍, 특정 일본 애니메이션 스타일, 실사풍, 3D 렌더링 스타일 등)

- **AI 활용 목적**: 이미지의 시각적 일관성을 맞추기 위해, 미드저니의 Style Reference 기능이나 스테이블 디퓨전의 특정 스타일 로라(LoRA)를 적용하는 데 참고합니다.
- **권장 사항**: 가능하면 대상 캐릭터와 독립적으로 '느낌' 자체가 잘 드러나는 스타일 이미지가 좋습니다.
