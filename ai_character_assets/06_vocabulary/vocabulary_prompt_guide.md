# 🎨 생존 단어장 그래픽 프롬프트 가이드라인

본 문서는 '생존 단어장'의 핵심 단어들을 시각화할 때 일관된 스타일과 교육적 효과를 유지하기 위해 작성되었습니다.

## 1. 핵심 디자인 원칙
- **Minimalism & Focus (미니멀리즘과 집중)**: 불필요한 배경은 배제하되, 개념 전달에 필수적인 '최소한의 컨텍스트'(예: 전용면적 시 벽체, 침대 등)는 포함하여 실재감을 부여합니다.
- **Selective Character Use (선택적 캐릭터 활용)**: 기본적으로 사물 중심을 지향하나, 관계성(예: 중개보수)이나 감정 전달이 필수적인 경우 프로젝트 캐릭터(멍멍이, 불독 등)를 적극 활용합니다.
- **Modern Document Style (현대적 서류 스타일)**: 문서(건축물대장 등)를 형상화할 때 두루마리보다는 일상적인 '종이 서류'의 적층 구조와 집게, 도장 등을 활용합니다.
- **Material Contrast (질감 대비)**: 전체적으로는 펠트 질감을 사용하되, '문서(Paper)'를 표현할 때는 날카롭고 매끄러운 실제 종이 질감을 사용하여 사물(집, 캐릭터)과의 시각적 대비를 통해 공식 문서임을 강조합니다.
- **No Text (텍스트 금지)**: 직접적인 글자는 배제하되, 선(Lines)이나 면(Blocks)을 활용하여 문서의 레이아웃을 추상적으로 형상화합니다.
